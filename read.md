# Remove All Occurrences

A C++ program that removes all occurrences of a given element from a deque.

## Description

This project demonstrates how to traverse a deque and remove every occurrence of a specified value.

The program checks each element and removes it when it matches the target value.

## Concepts Used

* C++ `deque`
* Loops
* Conditional statements
* `erase()`
* Iterators
* Searching and removing elements
* Boolean/flag logic

## Example

**Input:**

```text
Deque: 1 2 3 2 4 2 5
Target: 2
```

**Output:**

```text
1 3 4 5
```

All occurrences of `2` are removed from the deque.

## Purpose

This project was created to practice working with STL containers and understand how to safely remove multiple elements while traversing a deque.

## Language

C++
